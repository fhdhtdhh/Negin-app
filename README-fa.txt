نصب اپلیکیشن نگین
==================
این پوشه یک اپلیکیشن وب قابل‌نصب (PWA) است و بعد از نصب مثل یک برنامه‌ی معمولی با آیکون خودش باز می‌شود.

روش سریع (حدود ۲ دقیقه، رایگان):
۱. کل این پوشه را در سایت netlify.com/drop بکشید و رها کنید (یا روی GitHub Pages بگذارید) تا یک آدرس https بگیرید.
۲. آدرس را در Chrome گوشی باز کنید.
۳. منوی ⋮ ← «Install app / نصب برنامه».  (آیفون: Safari ← Share ← Add to Home Screen)

فایل APK برای اندروید:
بعد از آنلاین کردن، آدرس را در pwabuilder.com وارد کنید و گزینه‌ی Android را بزنید؛ فایل APK می‌دهد.

نکته: باز کردن مستقیم index.html از حافظه‌ی گوشی نصب نمی‌شود؛ نصب فقط از آدرس https کار می‌کند.
